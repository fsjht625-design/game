> **轉動粉甜骰子，喚醒創作靈感。一鍵開啟無限想像的浪漫冒險！**
`The Tale-Weaver's Dice` 是一款集結 3D 擬真物理骰子 與 創作畫布 的一站式寫作靈感平台。透過隨機擲出的圖示組合與提示，輔助創作者、語文教育者及腦力激盪團隊迅速建構故事劇情轉折。
---
📖 專案緣由與動機 (Motivation)
在寫作、教學或腦力激盪的過程中，「缺乏靈感」與「不知如何下筆」常常是創作者面臨的最大障礙。傳統實體故事骰子雖然有趣，但存在攜帶不便、圖示固定且無法即時記錄文字等限制；而現有的線上隨機產生器多為 2D 平面刷新，缺乏互動的「儀式感」。
本專案的開發動機為：
創造極具儀式感的寫作工具：結合 CSS 3D 視覺效果與 Web Audio 原生音效，賦予數位骰子如實體滾動般的手感與樂趣。
建構「靈感至產出」的完整閉環：不只給出圖示，更提供圖意解讀提示與寫作畫布，讓使用者可以在同一個介面完成「擲骰 -> 激發靈感 -> 線上寫作 -> 匯出文章」的全過程。
輕量與零門檻使用：採取單一 Web 檔案架構，無需安裝額外庫或多媒體檔案，開啟即玩。
---
✨ 核心特色 (Key Features)
🎲 CSS 3D 擬真旋轉效果：採用原生 CSS 3D Transforms 實現多圈翻轉與擬真減速滾動。
🔊 Web Audio 原生合成音效：無需載入外部 MP3 音訊，程式化即時生成逼真的碰撞音效。
🎨 多款主題圖示卡組：內建「天氣與自然」、「奇幻冒險」、「情感與生活」、「角色與遭遇」等豐富主題。
🛠️ 彈性自訂六面：支援自由修改骰子六面的圖示代碼 (FontAwesome)、名稱與故事提示（Hint）。
✍️ 一站式寫作畫布：內建文字編輯器，支援一鍵複製文章與導出 `.txt` 檔案。
🌸 馬卡龍粉色系美學：視覺採用舒適亮麗的粉嫩漸層與 Glassmorphism 玻璃擬態質感。
---
🛠️ 技術架構 (Tech Stack)
前端視覺：HTML5, CSS3 (CSS 3D Transforms)
UI 樣式與圖示：Tailwind CSS, FontAwesome 6
邏輯與音效引擎：Vanilla JavaScript (ES6+), Web Audio API
---
🚀 開發歷程 (Development Journey)
原型設計 (Prototype)：完成 3D 骰子立體盒構建與基礎旋轉算式，實作音效合成。
體驗優化 (UX & Theme)：引進多主題選擇器、自訂六面模組，以及創作畫布一鍵下載功能。
專案分析與企劃：深入評估優缺點、進行市場差異化分析，並規劃社群票選機制。
全功能一頁式平台 (V2.0)：整合高質感展示封面、遊戲平台、專案分析與社群投票互動卡片。

📊 專案分析與差異比較 (Project Analysis)
核心優勢 vs 潛在改進空間
類別	特性說明
核心優勢 (Pros)	• 3D 擬真視覺與即時音效反饋，極具沉浸感。<br>• 寫作閉環整合，支援文字導出。<br>• 多主題與彈性自訂功能。<br>• 零安裝單一檔案，載入極快。
