專案分析與市場差異 (Project Analysis)

全面評估當前設計的技術與體驗優勢、潛在改進空間，以及與市面上傳統線上隨機骰子的亮點比較。

核心優勢 (Advantages)

  • 3D 擬真視覺與即時音效反饋 採用 CSS 3D Transform 多圈翻轉與擬真減速，結合原生 Web Audio 程式化撞擊音效，極具儀式感。
  • 「一站式」創作成品閉環 不只擲骰，更整合靈感引導卡與即時創作畫布，支援一鍵複製與匯出文字檔。
  • 多主題卡庫與彈性自訂六面 內建 4 種常見情境主題（天氣、奇幻、情感、角色），並允許使用者自由替換 Icon 與關鍵字。
  • 單一檔案與輕量效能 零安裝無外部影音載入門檻，開啟速度極快、資源耗用低，適應多種行動裝置。

潛在改進空間 (Disadvantages)

  • 自訂圖示具備基礎門檻 目前自訂需要輸入 FontAwesome 代碼（如 `fa-dragon`），新手使用者可能需要點選清單輔助。
  • 非完全物理碰撞引擎 動態為隨機角度角度動畫算式而非 Cannon.js 物理模擬，雖然效能高但落點呈現相對規律。
  • 尚未整合雲端歷史紀錄 目前草稿保存在當前瀏覽器視窗中，重整分頁前需手動下載文字檔保存。

與市面上其他產品的不同之處

比較項目 一般線上骰子 / 隨機抽卡工具 本專案 (3D Story Dice)
視覺呈現與動態 多為 2D 圖示平面隨機刷新。 原生 CSS 3D 立體旋轉骰子，具備視覺翻轉與陰影質感。
創作介面整合 僅顯示結果，使用者需另開 Word 或筆記本寫作。 整合靈感提示與寫作畫布，邊看圖文邊創作，一鍵匯出。
意涵輔助提示 僅給出抽象圖案，新手容易發呆無從下筆。 自動解析圖卡意涵（Hint），輔助快速建構故事轉折。
技術載入資源 依賴大型 3D 繪圖庫或 MP3 音訊檔，載入較慢。 純原生 3D + Web Audio，零外部多媒體檔案，秒開即玩。

社群/使用者 5 大票選題目規劃

為蒐集使用者建議與產品後續叠代方向，規劃以下 5 大社群互動票選主題：

型態一：新主題需求

「下一個最希望新增的骰子主題是什麼？」

  • 1. 賽博龐克與科幻未來 🤖
  • 2. 校園日常生活與青春故事 🏫
  • 3. 神話傳說與怪談懸疑 👻
  • 4. 職場冒險與商業戰場 💼

目的：掌握圖示庫擴充的優先順序。

型態二：功能優先級

「你覺得遊戲目前最需要優先加入哪一個新功能？」

  • 1. AI 故事開頭產生器 🤖
  • 2. 內建點選式圖示選擇器 🎨
  • 3. 雲端歷史紀錄與自動存檔 ☁️
  • 4. 允許上傳自訂圖片 🖼️

目的：確定後續技術開發的資源分配。

型態三：寫作玩法

「如果加入寫作挑戰模式，你最想體驗哪一種？」

  • 1. 3 分鐘限時極速寫作 ⏱️
  • 2. 指定結局大反轉 🔄
  • 3. 每日全網同台寫作牆 🧱
  • 4. 雙人故事接龍模式 👥

目的：發掘遊戲化玩法以提升黏著度。

型態四：視覺風格

「你最喜歡哪一種骰子與介面的視覺主題風格？」

  • 1. 粉紅馬卡龍甜美風格 🌸 (當前)
  • 2. 復古羊皮紙與中古世紀 📜
  • 3. 溫暖木質與手繪繪本 🎨
  • 4. 8-Bit 像素懷舊電玩風 🎮

目的：評估主題面板 (Skins) 開發意願。

型態五：社群活動

「如果舉辦『故事骰子創作大賽』，你最看重哪種獎勵？」
